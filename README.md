# mateuspachela · portfolio

Portfólio pessoal de Mateus Pachela, Software Engineer no BTG Pactual e estudante de Engenharia de Computação na Unicamp.

- **Stack:** Astro 7, ilhas React, Motion, Lenis
- **Hero:** um console de agente roteirizado (`src/components/AgentConsole.tsx`)
- **Idiomas:** português em `/` e inglês em `/en/`
- **Para agentes:** o mesmo conteúdo em Markdown na visão *Machine* e em `/llms.txt` e `/en/llms.txt`
- **Conteúdo:** `src/data/pt.ts` e `src/data/en.ts`, com o mesmo formato

```bash
npm install
npm run dev     # http://localhost:4321
npm run build   # gera dist/
```

Deploy automático na Vercel a cada push na `main`.
